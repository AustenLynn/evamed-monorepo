## 1. Repo, environments, how to run things

- Monorepo: `frontend/evamed` (Angular 22, NgModules with `standalone: false`, Vitest) and
  `backend/evamed-api` (Django 5.2 + DRF, PostgreSQL 17). Auth is Firebase (`evamed-ac3f8`);
  the backend verifies Firebase ID tokens (`profiles_api/authentication.py`).
- The only deploy target is **AWS Lightsail dev** (`dev.evamediber.click`, region `us-east-1`),
  deployed by the `deploy` job in `.github/workflows/tests.yml` after backend, frontend and audit
  jobs pass on `main`. Vercel is gone.
- Local node is old. Run everything through node 22:
  - tests: `npx -y -p node@22 node node_modules/@angular/cli/bin/ng.js test --watch=false` (full suite)
  - build: `npx -y -p node@22 node node_modules/@angular/cli/bin/ng.js build`
  - lint: `npx -y -p node@22 npx eslint <files>`. Repo-wide lint already fails on main; keep
    touched files clean. Don't use `--fix` on files containing `̀-ͯ` regex escapes.
  - `npm audit fix --omit=dev` prunes dev deps from `node_modules`; run `npm ci` afterwards.
- Django tests run only in CI (no local Django install). For local checks, import pure modules
  (e.g. `projects_api/explorer/derive.py`) with `python3 -I`.
- Push (the plain remote has no credential helper):
  `timeout 90 git -c credential.helper= -c credential.helper='!gh auth git-credential' push https://github.com/AustenLynn/evamed-monorepo.git main && git update-ref refs/remotes/origin/main HEAD`,
  then watch CI with `gh run list/watch/view`.
- Dev server commands (port 22 is opened per run for the caller's IP):
  `AWS_PROFILE=evamed-dev deploy/with-ssh.sh ssh -o BatchMode=yes ubuntu@dev.evamediber.click "bash /opt/evamed/src/deploy/dc.sh exec -T api python manage.py <cmd>"`.
  Pipe a script into `... manage.py shell` for one-off reads. Some networks block outgoing
  port 22; check with `timeout 8 bash -c "</dev/tcp/github.com/22"` first.
- The dev database is **not** reseeded on deploy. Catalogue data changes need the fixture (for
  fresh installs) **and** an explicit write on dev (management command or shell script).
