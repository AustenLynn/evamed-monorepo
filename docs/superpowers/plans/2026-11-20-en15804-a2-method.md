# EN 15804+A2 Method Switch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make EN 15804+A2 EVAmed's active impact method behind a site-wide setting, import 125 ECO Platform EPDs, re-score ecoinvent with EF v3.1, and show A2-only results with a warning for anything left out.

**Architecture:** `PotentialType.method` plus `settings.EVAMED_IMPACT_METHOD`; one module (`projects_api/methods.py`) answers "which indicators are active" and "which entities are current". User-facing indicator lists, the explorer (which feeds every picker), Excel templates and `ProjectResultsView` go through it; `/materials/` and other catalogue lists stay unfiltered so old projects keep resolving their rows.

**Tech Stack:** Django 5.2 + DRF, PostgreSQL 17, Angular 22 (NgModules, Vitest).

**Spec:** `docs/superpowers/specs/2026-11-20-en15804-a2-method-design.md`

## Global Constraints

- Method values: `'CML'` and `'EN15804+A2'`. Setting `EVAMED_IMPACT_METHOD`, env-driven, default `'EN15804+A2'`; deploy first with `CML` (rollout step 1).
- Never delete or modify CML rows (indicators, values, materials). Old projects must open with every stored row.
- `frontend/evamed/src/app/calculos/*`: only the approved edit to `determinaValorCarbono`'s `ajustarNombre("Calentamiento Global")` lookup. Any other change there: stop and ask the owner.
- No new dependencies. No raw hex in explorer SCSS (use `--ev-*` tokens).
- ECO Platform EPD files are licensed: never commit them; tests use small synthetic ILCD JSON.
- ecoinvent: no dataset fetch until the owner approves the exact number.
- Commit per task; push only when the owner asks (push deploys dev).
- Never print `~/ecoinvent/.env`, `~/ecoplatform/.env`, `deploy/.env.aws`.
- Commands: backend tests `cd backend/evamed-api && python manage.py test projects_api.<module>` against the local PostgreSQL test DB (CI also runs them); frontend `cd frontend/evamed && npx -y -p node@22 node node_modules/@angular/cli/bin/ng.js test --watch=false`; build `... ng.js build`; lint touched files `npx -y -p node@22 npx eslint <files>`.

## Review Focus

1. An old project (only CML materials) under A2: results open, every indicator is A2, totals are 0 and the warning lists every material; no 500, no crash on the comparison page. → Task 4 test `test_old_project_under_a2_warns_not_crashes`, Task 5 spec.
2. Mixed project (one ECO + one CML material) for an ineligible user: still 404 (ECO access unchanged) and the warning payload never names ECO rows to anyone who can't open the project. → Task 4 test `test_warning_respects_eco_access`.
3. Autosave of an old project's materials stage after the switch does not drop rows whose materials are no longer offered (`/materials/` unfiltered). → Task 3 test `test_materials_endpoint_stays_unfiltered`.
4. A material with 12 of 13 A2 indicators is not offered and is listed in the warning, never summed as 0. → Task 2 test `test_missing_one_indicator_is_not_current`, Task 4 test `test_partial_material_listed`.
5. Switching the setting back to `CML` restores today's behaviour exactly (indicators, explorer, results). → Task 4 test `test_cml_setting_matches_legacy_results`.

Behaviour:
- Name `"{family}_{name} marca {owner}_{geo}"`; `database_from='ECO Platform'`; `provider_code='eco_platform'`; description = EPD description (first ~500 chars) + declared unit + `https://portal.eco-platform.org/epds/{ra}/{uuid}`.
- Skip by name: `Steel Slang`, `Bekron Cementitious adhesives`, `PEGAMENTO MEDIO PVC TRANSPARENTE`, and any EPD without A2 compliance (`Reinforcing steel in bars`). Expected: 125 imported.
- Unit: flagged `referenceFlowProperty` `referenceUnit`, per one EVAmed unit: 1000 kg → `Ton`, kg → `Kg`, m² → `m²`, m³ → `m³`, m → `m`, pcs → `Pz` (values ÷ `resultingflowAmount` when the declared amount isn't 1 of that unit). - `Conversions`: tonnes per declared unit from `Mass` property (kg ÷ 1000) or `gross density` × 1 m³; else none.
- Idempotent by `eco_epd_uuid`: re-run updates values/description, never duplicates.
- Dry run prints: count, per-family counts, every inferred unit, every material without mass, every skip with reason.
